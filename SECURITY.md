# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The VidyutGati security team and **[ProNextLabs](https://github.com/pronextlabs)** take security seriously.

If you discover a security vulnerability within VidyutGati, please do **NOT** report it publicly through GitHub issues. Instead, please report it directly via email to:

📧 **security@pronextlabs.com** (or open a private security advisory on GitHub)

Please include:
- A description of the vulnerability
- Steps to reproduce or proof of concept
- Potential impact

We appreciate your responsible disclosure and will acknowledge your report within 48 hours.
